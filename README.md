# 酒馆角色卡工具集

《机损营业中！》《高岭之花》项目配套的单文件 HTML 编辑器，双击即可用，无需服务器。

## 工具

| 工具 | 位置 | 用途 |
| --- | --- | --- |
| 物品编辑器（官方版） | `工具/物品编辑器/物品编辑器-官方版.html` | 编辑官方候选物品，导出 JSON 交官方筛选合并 |
| 物品编辑器（玩家版） | `工具/物品编辑器/物品编辑器-玩家版.html` | 编辑玩家自定义物品，导出后在卡内创意工坊导入 |
| 开局预设编辑器 | `工具/开局预设编辑器/开局预设编辑器.html` | 编辑开局预设（机器人 / 主人两条路径 + 预设图），导出 JSON 或单预设数据图 |

## 使用

直接用 Chrome / Edge 打开对应 HTML。数据存在本机浏览器 localStorage，关闭页面不丢失；支持 JSON 与 PNG 内嵌数据两种导入导出。

## 数据格式

- 物品：`items/v1`（official / player / disabled）
- 开局预设：`opening/v1`
- 图片导出通过 PNG tEXt 元数据内嵌 base64 JSON，发送时需选原图。

## 托管

全部为单文件 HTML，可直接放到任意静态托管（GitHub Pages / jsdelivr / 自建服务器）。
